# Shared experiment API — freeze before parallel coding

All package modules use pathlib, plain dicts with JSON serializable values, NumPy arrays and pandas frames. No Torch import in package __init__, protocol, suite import path, data or metrics. Lazy import training/model only for target execution. Read SPEC for complete acceptance criteria. Names/signatures below are binding; report change needs before deviating.

## protocol.py (orchestrator)
CLASSES tuple5 and LEADS tuple12 as SPEC. `load_protocol(path: Path) -> dict` validates exact config. `protocol_hash(protocol: dict) -> str` canonical content hash. `build_jobs(protocol: dict) -> list[dict]` each has id (experiment_id + seed), experiment_id, seed, variant (the full variant spec dict), normalization, training (copied shared training dict). `select_experiment(protocol, results: list[dict]) -> dict` requires all jobs completed, uses result.val_metrics.macro_auroc then macro_average_precision; returns selected_experiment/reference_experiment/rows and evidence, no test input. `write_json(path,value)` atomic JSON allow_nanFalse; convert NumPy/nonfinite to JSON friendly/null as appropriate. `code_fingerprint() -> str` hashes all ptbxl_experiments/*.py content sorted filenames, no absolute paths.

Config schema keys: schema_version=1, suite_id string, source={version,expected_fingerprint,expected_audit_sha256,expected_records,expected_accepted}, seeds=[42,2024,3407], reference_experiment='reference100', variants=[{id,source:'official100'|'release500',fs:100|200|500,filter:'minimal'|'bandpass_0.5_40'}], experiments=[{id,variant:<variant id>,normalization:'global'|'per_lead'}], training={architecture:'resnet1d_wang',epochs:50,batch_size:128,learning_rate:0.01,weight_decay:0.01,crop_seconds:2.5,eval_stride_seconds:1.25,aggregation:'max',workers:0,amp:true,scheduler:'onecycle',kernel_policy:'scale_odd'}, evaluation={bootstrap_replicates:1000,bootstrap_seed:42}.

## data.py (data worker)
`verify_release(release_dir: Path, *, expected_fingerprint: str|None=None, expected_audit_sha256: str|None=None, full: bool=True) -> dict`: read-only portable audit, full accepted-array checksum/shape checks. Fixture tests can omit anchors and use a complete fixture audit with readyTrue/fixtureFalse and counts derived from fixture; real CLI enforces pinned source/counts. Return source_fingerprint, accepted_records, source_records, split_counts, audit_sha256, classes, leads.
`prepare_variant(release_dir: Path, raw_dir: Path, cache_root: Path, variant: dict, *, allow_download: bool=False) -> Path`: return immutable completed variant directory; official100 files in cache_root/source100 (not raw_dir). raw_dir contains pinned SHA256SUMS.txt and source metadata for filename_lr hashes. Read original arrays for release500 transforms. Validate existing cache hashes; atomic per split; metadata ready only after all. progress print flush periodically. Source identity includes audited manifest + transform/source code and NumPy/SciPy/WFDB versions. Group both normalization options in same cache.
`verify_prepared(directory: Path) -> dict`: full cache checksum/shape/manifest validation; returns metadata.
`load_prepared(directory: Path, split: str, normalization: str) -> tuple`: (X memmap float32[N,12,T], manifest DataFrame, mean float64[12,1], std float64[12,1], metadata dict). Quick metadata/manifest binding and shape checks; full hashes are verified by suite before training. Manifest has ecg_id,patient_id,split,y_NORM,y_MI,y_STTC,y_CD,y_HYP plus source noise columns. No relative path traversal; no load pickle.
`variant.json` schema: schema_version1, readyTrue, fingerprint (cache identity), source_fingerprint, variant (input spec), fs, classes, leads, normalization={global:{mean:[scalar],std:[scalar],fit_split:'train',train_records:N},per_lead:{mean:list12,std:list12,fit_split:'train',train_records:N}}, splits={train:{signals:'train.npy',manifest:'train.csv',count:N,signals_sha256,manifest_sha256},validation:...,test:...}. Extra provenance keys allowed. Metadata identity must be validated; write variant.json last and no mutable external absolute source paths in fingerprint.

## metrics.py (engine worker; NumPy/SciPy only)
`multilabel_metrics(y_true, probabilities, thresholds=None) -> dict`: keys macro_auroc, macro_average_precision, macro_f1 (if thresholds), per_class (by CLASSES, supports/validity), brier_score. Scalars plain JSON friendly; undefined AUROC/AP null; macro over defined labels with count disclosed. Shapes defaultK5; fixtures can5. Validate values and IDs elsewhere. Use standard rank/tie-correct AUROC and non-interpolated AP definitions; no sklearn dependency needed. Fixture expected values must verify ties/single-class/all-negative cases.
`fit_thresholds(y_true, probabilities) -> np.ndarray[5]`: validation only deterministic F1 maximizing thresholds, tie rule documented.
`patient_bootstrap(y_true, probabilities, patient_ids, *, thresholds=None, n_bootstrap=1000, seed=42) -> dict`: resample patients with all their rows, report percentile95% interval/valid counts for macroAUROC/AP/F1 when applicable. Avoid silent dropping undefined-class draws without documenting valid counts.

## model.py / training.py (engine worker)
`build_model(fs: int, num_classes: int=5)` in model.py implements SPEC architecture independent PyTorch port. Expose parameter/kernel details for reporting. No model runs on laptop.
`train_run(job: dict, prepared_dir: Path, run_dir: Path, *, identity: dict, device: str='cuda', resume: bool=True) -> dict`. identity={protocol_hash,code_fingerprint,source_fingerprint,prepared_fingerprint}; checkpoint identity also binds job+runtime. result={job_id,experiment_id,seed,status:'completed',val_metrics,run_dir:<str>,best_epoch,elapsed_seconds,peak_gpu_memory_bytes}. Writes validation_predictions.npz with ecg_id,patient_id,y_true,probabilities; val_thresholds.npy (no pickle); history.json/csv, result.json, best.pt,last.pt, hashes/status/errors. Completed reuse must verify artifact hashes and identities, not trust status alone. Atomic epoch checkpoints; resume same seed/epoch, crops and shuffle, optimizer/scheduler/scaler/RNG/history/best. Stochastic dropout RNG restore. Include Python/NumPy/torch CPU/CUDA state serializable under weights_onlyTrue where possible. Last contains sufficient best-state recovery for crash consistency. A changed job/source/code/runtime must refuse resume into same run_dir.
`predict_run(job: dict, prepared_dir: Path, run_dir: Path, split: str, *, device: str='cuda') -> dict`: reload best verified weights and use fixed eval windows; returns ecg_id ndarray,patient_id ndarray(str),y_true ndarray,probabilities ndarray, all aligned. No fitting or threshold selection on test. Use classwise max of window sigmoid probabilities (not max logits then averaging). Split validation/test allowed, suite controls test gate.
`target_smoke(training: dict, *, device: str='cuda') -> dict`: CUDA target-only synthetic model+loss/backward at fs500/configured batch, checkpoint load/resume smoke in tempdir, test shapes at3fs. No real dataset training. Raise clear errors before long jobs. Torch-target tests require ECG_TARGET_TESTS=1 and are not executed locally.

## suite.py and CLI (orchestrator)
Commands `plan`, `preflight`, `run-suite`, `collect`, `summarize`; options --config --release-dir --raw-dir --work-dir --device cuda --allow-download. plan/collect/summarize import no Torch and run no model. run-suite preflight full receiving audit and target_smoke, prepare/verify5 variants,21 train_run calls, select validation winner only after all complete, persist immutable selection.json, then predict reference+winner tests. For ensemble metrics align seed IDs exactly; mean probabilities; fit ensemble thresholds on mean VALIDATION probabilities only. Test ensemble CI via patient_bootstrap. Keep per-seed metrics and validation planned-contrast deltas. Incomplete jobs => no automatic test; errors/status plus nonzero exit; still collect diagnostics. Persist frozen protocol, source identity and runtime. OS-owned lock for suite, no stale lock requiring unsafe file deletion; heartbeats and console/file logs.
