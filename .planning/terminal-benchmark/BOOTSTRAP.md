## Architecture and ABI

- `cohort_digest(records_path: Path) -> str`: canonical SHA256 of every record's semantic cohort identity and accepted waveform-byte SHA, sorted integer ECG ID. Read CSV only; no waveform reads. Fixed ordered columns: ecg_id,patient_id,strat_fold,split,y_NORM,y_MI,y_STTC,y_CD,y_HYP,has_label,status,reason,filename_hr,filename_lr,npy_path,signal_sha256,fs,n_samples,units. Canonical integer numeric columns using Decimal to normalize '1'/'1.0'; empty numeric ->null; text empty->empty string; enforce unique IDs/finite integers/binary labels/known split/status. Serialize {'columns':columns,'rows':rows} with sort_keys=True,separators=(',',':'),ensure_ascii=False,allow_nan=False UTF8, SHA256. Preserve empty signal fields for excluded records. Include all21,799 rows, not just accepted.

Full=True verifies every accepted array SHA/shape/finiteness. - `prepare_school(config_path:Path, contract_path:Path, raw_dir:Path, release_dir:Path, cache_dir:Path, work_dir:Path, *, allow_download:bool=False) -> Path`: returns work_dir/target_protocol.json. Stale ready audit fails full verification; do not overwrite a corrupted ready release. Interrupted non-ready release uses existing core fingerprint/sidecar resume; wrong runtime/core must fail with new-directory instruction.
