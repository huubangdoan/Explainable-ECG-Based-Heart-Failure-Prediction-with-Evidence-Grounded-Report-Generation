## Decisions
Use the upstream resnet1d_wang architecture as a modern PyTorch port; benchmark-aligned on PTB-XL1.0.3, explicitly NOT a bit-exact reproduction of old Fastai/results. Freeze upstream commit cdbf4e66d7e57d9b6a2657b6024716212b8d0afa. Reference uses official records100, minimal and scalar train-global standardization. Common cohort is the existing accepted21387 records, including identical split/IDs for every experiment. Thus reference also excludes train ECG12722, unlike upstream default; disclose this and version/runtime/checkpoint-selection differences.

Seven experiments x seeds42,2024,3407 =21 jobs, one GPU sequentially. IDs: reference100 (official100/minimal/global), derived100 (release500→100/minimal/global), derived200 (release500→200/minimal/global), minimal500_global (release500/minimal/global), minimal500_per_lead (current approach), bandpass500_global, bandpass500_per_lead. Shared physical caches: official100_minimal, derived100_minimal, derived200_minimal, minimal500, bandpass500. Reference vs derived100 checks official versus our resampler; derived100/200/minimal500_global isolates frequency; minimal500_global/per_lead isolates normalization; minimal500 versus bandpass500 at same normalization isolates filtering. This is not all frequency×filter interactions.

All transforms on full10s physical mV before cropping. Optional Butterworth design order4 SOS forward-backward0.5–40Hz at500Hz; polyphase anti-alias resampling for100/200. Fit scalar and12-lead population mean/std from accepted train only for each cache. Do not fit validation/test or use per-record zscore. Train crop2.5s, deterministic random start by seed/epoch/ECG index; validation/test2.5s windows stride1.25s, aggregate sigmoid probabilities per ECG by max (upstream pinned-code default). Keep all evaluation windows within one ECG, label once per record. Upstream paper text discussed5s but pinned current code defaults2.5s: document this distinction.

Architecture at100Hz: stem Conv1d12→128,k7,stride1,pad3,no bias +BN+ReLU, no stem pool. Three BasicBlocks (two convs k5,k3, widths128); block strides1,2,2, projection Conv1d1x1+BN on stride change; residual sum+ReLU. Adaptive max and mean concat256; BN256→Dropout.25→Linear256/128→ReLU→BN128→Dropout.5→Linear128/5. Scale temporal kernels by fs/100, rounding even values up to odd; keep widths/strides fixed and disclose temporal-step/parameter differences. Train50 epochs, batch128, BCEWithLogitsLoss unweighted, AdamW lr/max_lr0.01, wd0.01, OneCycleLR pct_start.3/div_factor25/final_div_factor1e4, AMP enabled on CUDA. Fixed settings all variants. No LR finder, no early stop; keep last and best validation record-level macro AUROC (earlier epoch wins ties). These modern optimizer/scheduler/checkpoint details are disclosed departures from old Fastai.
